# TravelTrucks — оренда кемперів 🚐

Вебзастосунок для компанії **TravelTrucks**, яка займається орендою кемперів. Проєкт дозволяє користувачам переглядати каталог доступних транспортних засобів, фільтрувати їх за різними параметрами, переглядати детальну інформацію, галерею зображень, відгуки та оформлювати бронювання.

---

## 🚀 Основні функції

- **Домашня сторінка (`/`)**: Вітальний банер із закликом до дії (`View Now`) для швидкого переходу до каталогу.
- **Сторінка каталогу (`/catalog`)**:
  - Відображення списку кемперів із пагінацією у форматі **Load More** (по 4 елементи за раз) за допомогою `@tanstack/react-query`.
  - Система фільтрації на бекенді (за локацією, типом кузова, типом двигуна та трансмісією).
  - Кнопка «Show more», яка відкриває детальну сторінку обраного кемпера в новій вкладці.
- **Сторінка деталей кемпера (`/catalog/[camperId])`**:
  - Повна інформація про транспортний засіб (характеристики, ціна, опис).
  - Інтерактивна галерея зображень із прев'ю (`Swiper`).
  - Блок відгуків користувачів із п’ятизірковою шкалою рейтингу.
  - Робоча форма бронювання з валідацією (`Formik` + `Yup`) та нотифікаціями (`react-hot-toast`).

---

## 🛠 Технології та стек

- **Фреймворк:** [Next.js](https://nextjs.org/) (App Router)
- **Стейт-менеджмент:** Zustand (для фільтрів)
- **Запити та кешування:** TanStack React Query
- **Форми та валідація:** Formik, Yup
- **Стилізація:** CSS Modules
- **UI / Додатково:** Swiper.js, React Hot Toast, React Icons, Axios
